type Task struct {
    ID int
    Title  string
    status string
    queued bool
}

Go has a very simple visibility rule.

Capital first letter = exported
ID , Title
Other packages can access them.

BUT >>>

Lowercase = unexported
status , queued
Other packages cannot directly access them.

DIFFERENT FILES
     ↓
doesn't matter for export visibility
DIFFERENT PACKAGES
     ↓
export rules apply

MODULE
  ↓
PACKAGE
  ↓
FILES
  ↓
TYPES / FUNCTIONS / VARIABLES

But importantly:

Files don't import files.
Packages import packages.

THE _ CHARACTER :

The _ is called the blank identifier.

It means:
"Receive this value, but intentionally throw it away."
So:  id, _ := strconv.Atoi(...)

You're explicitly saying: 
     "Yes, I know there's another value. I'm intentionally ignoring it."
